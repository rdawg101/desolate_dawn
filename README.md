--- Desolate Dawn ---

Desolate Dawn will be a full-stack web project centered around a zombie mini-game where the player has to fight endless hordes in the dark with a dim light emitting from them to see enemies around them. 
The player will have options to multiple weapons and will encounter multiple different zombie types as they survive.

--- Current plans for implementation ---
- start screen
    - play button
    - leaderboard
    - settings
    - credits
- game screen (navigated to from play button)
    - wave number
    - zombie count
    - player and zombie sprites
    - player health UI
    - player weapons (taskbar, weapons will unlock at certain waves)
    - settings
- game over screen (once player reaches 0 health)
    - tells player game over
    - displays wave count player was able to reach
    - total zombie kill count
    - retry function
    - main menu button
 
** game screen and game over screen most likely will be made in Unity **

--- Planned Tech Stack ---
- Main Game: Unity/WebGL export
- Frontend Website: React, Vite
- Backend: Node.js, Express.js
- Database: MongoDB Atlas, Mongoose
